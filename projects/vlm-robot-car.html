Prototype goal

Turn spoken intent and visual feedback into bounded robot actions

This project links a camera feed and natural-language commands to a locally hosted vision-language model, then uses a structured action interface to issue commands to a small mobile robot through an ESP32-based motor controller.

Lessons

Robotic AI needs safety at the interface

  • Free-form model output should not drive actuators directly; it needs a bounded command interface.
  • A useful demonstration must show latency and feedback behavior—not just a successful text response.
  • Communication, uncertainty and safety interlocks matter as much as language grounding.
